# Server Info

| Property | Type | Description |
| -------- | ---- | ----------- |
| `version` | `string` | The version number of the server |
| `supabaseURL` | `string` | The URL for the associated Supabase instance |
| `supabaseAnonKey` | `string` | The anonymous key for the associated Supabase instance |


### Example

```json
{
    "version": "1.0.0",
    "supabaseURL": "https://my-project-id.supabase.co",
    "supabaseAnonKey": "eyJhbGciOiJIUzI1NiIsInR..."
}
```
