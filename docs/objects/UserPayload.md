# User Payload

| Property | Type | Description |
| -------- | ---- | ----------- |
| `id` | `string` | The user's Supabase ID |
| `name` | `string` | The user's Discord username |
| `avatarURL` | `string?` | The URL for the user's Discord avatar |


### Example

```json
{
    "id": "0a76ebff-f3b9-4d2c-8126-be92dbb8cee6",
    "name": "ben.json",
    "avatarURL": "https://cdn.discordapp.com/avatars/318511797642592257/4d8313035ea42d81324db60231a7bce1.png"
}
```
